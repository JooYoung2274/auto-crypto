Coin Agents Office — 모의거래 프로그램 (Windows)
====================================================

■ 실행 방법

1. 압축을 푼 폴더에서 CoinAgentsOffice.exe 를 더블클릭합니다.

2. "Windows의 PC 보호" 파란 창이 뜨면
   → [추가 정보] 클릭 → [실행] 버튼 클릭

   이 경고는 바이러스라는 뜻이 아닙니다.
   코드 서명 인증서를 붙이지 않은 프로그램에 Windows가 기본으로 띄우는
   안내이며, 한 번 실행하면 다음부터는 뜨지 않습니다.

3. 처음 켜면 사용 안내가 3단계로 표시됩니다. 읽고 [시작하기]를 누르세요.


■ 창이 열리지 않거나 하얗게만 보일 때

Microsoft Edge WebView2 런타임이 필요합니다.
Windows 11과 최신 Windows 10에는 이미 들어 있지만, 없으면 아래에서
"Evergreen 부트스트래퍼"를 받아 설치한 뒤 다시 실행하세요.

   https://developer.microsoft.com/microsoft-edge/webview2/


■ 알아두실 점

- 이 프로그램은 모의거래 전용입니다. 실시간 시세로 매매를 흉내 내지만
  주문은 전부 가상이며, 실제 자금이 움직이지 않습니다.
- 거래소 계정이나 API 키가 필요 없습니다.
- 기본 전략이 들어 있어 실행 직후 바로 동작합니다.
- 조건이 맞지 않으면 아무 거래도 하지 않습니다. 하루 종일 거래가 없을 수
  있으며, 이는 고장이 아니라 정상 동작입니다.
- 상단 [전략 연구] 버튼은 20~45분이 걸립니다. 진행 중에는 창을 닫지 마세요.
- 인터넷 연결이 필요합니다 (시세 조회).


■ 데이터가 저장되는 곳

   %APPDATA%\CoinAgentsOffice\

   - coinagent.db          매매 기록
   - coinagent.log         실행 로그
   - coinagent-error.log   오류가 났을 때만 생성

프로그램이 켜지지 않는다고 문의하실 때 위 로그 파일을 함께 보내주시면
원인을 빠르게 확인할 수 있습니다.


■ 면책

과거 데이터 백테스트 성과는 미래 수익을 보장하지 않습니다.
이 프로그램은 교육 및 연구 목적의 시뮬레이터이며, 투자 권유가 아닙니다.
투자 판단과 그 결과에 대한 책임은 이용자 본인에게 있습니다.
