# 판매 페이지 문구 가이드

법적 리스크는 코드가 아니라 **광고 문구**에서 가장 자주 발생합니다. 국내에서
암호화폐 자동매매 도구 판매가 실제로 문제가 된 사례는 대부분 무허가 금융업이
아니라 **허위·과장광고 또는 사기**로 다뤄졌습니다. 아래 기준을 지키세요.

> 이 문서는 법률 자문이 아닙니다. 최종 문구는 변호사 검토를 받으세요.

---

## 절대 쓰면 안 되는 표현

| 금지 표현 | 이유 |
|---|---|
| "월 O% 수익", "연 O% 보장" | 수익 보장 — 사기·유사수신 소지 |
| "원금 보장", "손실 없는" | 위와 동일 |
| "승률 85%" (단독 강조) | 백테스트 조건을 뺀 성과 수치는 기만적 표시광고 |
| "AI가 알아서 벌어줍니다" | 수익 보장의 우회 표현 |
| "실계좌 인증 수익 캡처" | 모의거래 전용 상품과 불일치 — 허위광고 |
| "전문가 시그널", "리딩" | 투자자문·유사투자자문업 오인 소지 |

## 안전하게 쓸 수 있는 표현

- "규칙 기반 자동매매 **시뮬레이터**"
- "백테스트·워크포워드 검증 도구"
- "손절·분할진입·레버리지 상한을 코드로 강제하는 매매 규칙 엔진"
- "실시간 시세로 전략을 **모의** 검증"

성과 수치를 넣어야 한다면 **반드시** 아래 세 가지를 함께 표기하세요.

1. 백테스트 결과라는 사실
2. 검증 구간(기간)과 대상 심볼
3. "미래 수익을 보장하지 않습니다" 문구

> 예시: "2026년 6~7월 BTC·ETH 등 5종 15분봉 백테스트 기준 승률 43%
> (과거 데이터 시뮬레이션 결과이며 미래 수익을 보장하지 않습니다)"

---

## 상품 설명에 반드시 넣을 항목

```
■ 이 프로그램은 모의거래 전용입니다
  실시간 시세로 매매를 시뮬레이션하며, 실제 주문이 나가지 않습니다.
  거래소 계정이나 API 키가 필요 없습니다.

■ 수익을 보장하지 않습니다
  표시되는 모든 수치는 과거 데이터 백테스트 결과입니다.
  이 프로그램은 교육·연구용 시뮬레이터이며 투자 권유가 아닙니다.

■ 동작 방식
  - 조건이 맞지 않으면 거래하지 않습니다. 하루 종일 거래가 없을 수 있습니다.
  - 전략 연구 기능은 1회 실행에 20~45분이 소요됩니다.

■ 실행 환경
  - Windows 10 64비트 이상 (Microsoft Edge WebView2 런타임 필요)
  - macOS [최소버전] 이상
  - 인터넷 연결 필요 (시세 조회)

■ Windows 실행 시 보안 경고 안내
  코드 서명 인증서를 적용하지 않아 최초 실행 시 "Windows의 PC 보호" 창이
  표시됩니다. [추가 정보] → [실행]으로 진행하시면 되며, 이후에는 나타나지
  않습니다. 압축 파일 안 '사용안내.txt'에도 동일한 안내가 있습니다.

■ 환불 안내
  본 상품은 다운로드형 디지털 콘텐츠로, 다운로드 및 설치 후에는 청약철회가
  제한됩니다. 구매 전 상세 설명과 최소 사양을 확인해 주세요.
  (자세한 내용은 환불정책 참조)
```

마지막 환불 문구는 **결제 버튼 근처에 노출**해야 청약철회 제한이 유효합니다
(전자상거래법 제17조제6항).

## 하지 말아야 할 판매 형태

아래로 넘어가는 순간 소프트웨어 판매가 아니라 **무허가 금융업**이 될 수
있습니다.

| 형태 | 위험 |
|---|---|
| 구매자의 API 키를 받아 대신 운용 | 특금법상 미신고 가상자산사업자 (형사처벌) |
| 내 서버에서 구매자 자금으로 매매 | 위와 동일 |
| 수익 배분형(수익의 O% 수취) | 유사수신·투자일임 소지 |
| 오픈채팅방 매매 신호 제공 | 유사투자자문 오인, 사기 리스크 |

**지금 구조(구매자 PC에서 가상 자금으로만 동작)를 유지하는 것이 가장 안전한
형태입니다.**

## 판매 전 체크리스트

- [ ] 판매 페이지에 수익 보장·승률 단독 강조 문구가 없는가
- [ ] 성과 수치에 백테스트·기간·면책이 함께 붙어 있는가
- [ ] "모의거래 전용"이 제목 또는 첫 문단에 있는가
- [ ] 환불 제한 고지가 결제 버튼 근처에 있는가
- [ ] 이용약관·환불정책 링크가 게시되어 있는가
- [ ] 플랫폼(크몽 등) 금지 품목 규정을 확인했는가
- [ ] 저장소를 private으로 전환했거나 판매판을 분리했는가
