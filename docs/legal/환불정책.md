## 1. 기본 원칙

Coin Agents Office(이하 "프로그램")는 다운로드 방식으로 제공되는
**디지털 콘텐츠**입니다. 「전자상거래 등에서의 소비자보호에 관한 법률」
제17조에 따라 청약철회가 가능한 경우와 제한되는 경우를 아래와 같이 정합니다.

## 2. 청약철회가 가능한 경우

다음의 경우 구매일로부터 **7일 이내** 청약철회(전액 환불)가 가능합니다.

| 사유 | 설명 |
|---|---|
| 미다운로드 | 결제 후 프로그램을 **한 번도 내려받지 않은** 경우 |
| 실행 불가 | 판매 페이지에 명시된 최소 사양을 충족함에도 프로그램이 실행되지 않고, 회사의 지원으로도 해결되지 않는 경우 |
| 표시·광고와 다름 | 판매 페이지에 기재된 주요 기능이 실제로 제공되지 않는 경우 |
| 중대한 결함 | 프로그램의 핵심 기능이 정상 동작하지 않고 수정본 제공이 불가능한 경우 |

## 3. 청약철회가 제한되는 경우

다음의 경우 「전자상거래법」 제17조제2항제5호에 따라 청약철회가 제한됩니다.

- 프로그램을 **다운로드하여 설치·실행한 경우**
  (디지털 콘텐츠의 제공이 개시된 것으로 봅니다)
- 이용자의 단순 변심
- 이용자의 기기 환경, 운영체제 버전, 제3자 소프트웨어와의 충돌로 인한 문제
  로서 회사의 귀책으로 보기 어려운 경우
- 프로그램을 이용한 **모의거래 성과가 기대에 미치지 못한다는 사유**
  (프로그램은 수익을 보장하지 않으며, 이는 결함이 아닙니다)

> **중요**: 청약철회 제한이 유효하려면 **구매 전에** 그 사실을 명확히 고지해야
> 합니다(전자상거래법 제17조제6항). 판매 페이지 결제 버튼 근처에 아래 문구를
> 반드시 노출하세요.
>
> > "본 상품은 다운로드형 디지털 콘텐츠로, 다운로드 및 설치 후에는 청약철회가
> > 제한됩니다. 구매 전 상세 설명과 최소 사양을 확인해 주세요."

## 4. 환불 절차

1. [연락처 이메일] 로 **주문번호**와 **환불 사유**를 보내주세요.
2. 회사는 접수일로부터 3영업일 이내에 검토 결과를 회신합니다.
3. 환불이 승인되면 영업일 기준 3일 이내에 결제 수단으로 환급합니다.
4. 오픈마켓을 통한 구매는 해당 플랫폼의 환불 절차를 따릅니다.

## 5. 실행 문제 진단에 필요한 자료

"실행 불가"를 사유로 환불을 요청하시는 경우, 아래 파일을 함께 보내주시면
원인 확인 후 해결이 가능한 경우가 많습니다.

| 운영체제 | 로그 위치 |
|---|---|
| Windows | `%APPDATA%\CoinAgentsOffice\coinagent.log` 및 `coinagent-error.log` |
| macOS | `~/Library/Application Support/CoinAgentsOffice/coinagent.log` 및 `coinagent-error.log` |

## 6. 최소 사양

| 항목 | 요구 사항 |
|---|---|
| Windows | Windows 10 (64비트) 이상, Microsoft Edge WebView2 런타임 |
| macOS | macOS [최소버전] 이상 |
| 공통 | 인터넷 연결(시세 조회), 여유 디스크 공간 1GB 이상 |

> **작성 참고**: `[최소버전]`은 실제 빌드 환경에 맞춰 확인 후 기재하세요.
> GitHub Actions의 `macos-latest` 러너에서 빌드하면 해당 러너의 macOS 버전이
> 하한이 됩니다.
