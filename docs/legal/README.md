# 판매 관련 문서 (초안)

**모두 초안이며 법률 자문이 아닙니다. 판매 전 변호사 검토를 받으세요.**

| 문서 | 용도 |
|---|---|
| [이용약관.md](이용약관.md) | 라이선스 범위, 면책, 분쟁 해결 |

## 먼저 채워야 할 항목

세 문서에 `[ ]` 로 표시된 자리를 실제 값으로 바꾸세요.

```
[판매자명]  [사업자등록번호]  [통신판매업 신고번호]
[연락처 이메일]  [시행일]  [최소버전]
```

## 특히 주의할 두 가지

**1. 면책조항은 전부 면책이 될 수 없습니다.**
「약관의 규제에 관한 법률」 제7조에 따라 사업자의 고의·중과실을 전면 면책하는
조항은 무효입니다. 이용약관 제10조 제4항(고의·중과실 제외)을 삭제하지 마세요.

**2. 환불 제한은 사전 고지가 있어야 유효합니다.**
「전자상거래법」 제17조제6항에 따라, 다운로드 후 청약철회 제한을 적용하려면
**결제 전에** 그 사실을 고지해야 합니다. 판매 페이지 결제 버튼 근처에 환불
제한 문구를 노출하세요.

## 앱 내 고지

프로그램 첫 실행 시 3단계 안내가 표시되고, 마지막 단계에서 면책 확인
체크박스에 동의해야 시작할 수 있습니다. 확인 시각은 이용자 기기의
`localStorage`(`coinagent.consent.v1`)에 기록됩니다.

관련 코드: `frontend/src/components/Onboarding.tsx`

## 확인이 필요한 사항

- **플랫폼 정책** — 크몽의 금지 품목·카테고리 규정을 직접 확인하세요. 플랫폼
  환불 규정이 자체 환불정책보다 우선 적용됩니다.
- **가상자산 관련 입법** — 가상자산 자문업·일임업 규제를 포함하는 2단계 입법
  논의가 진행 중이었습니다. 판매 시점의 시행 여부를 확인하세요.
- **저장소 공개 범위** — 코드가 공개되어 있으면 유료 판매가 어렵습니다.
  private 전환 또는 판매판 분리를 먼저 처리하세요.
