# 매매가이드 PDF 분석 — 규칙인가, 재량 판단인가

원문: `매매가이드.pdf` (183쪽, 이미지 PDF). 아래 쪽 번호는 인쇄된 쪽 번호다.

> 이 문서는 **원문을 다시 읽지 않고도 대조할 수 있게** 남기는 요약이다.
> 이전에 분석해놓고 저장하지 않아 두 번 읽었다.

## 결론

**고정된 기계적 규칙 집합이 아니다.** 리스크 관리 쪽은 숫자로 못박혀 있고,
진입 판단은 여러 지표를 교차 확인하는 재량 판단이다. 가이드가 직접 그렇게
말한다:

> "체크리스트는 참고용이며 본인만의 매매 원칙을 세워 나가는게 중요합니다."
> — 2-4 매매 원칙과 트레이딩 전 체크리스트, p30

## 층 1 — 숫자로 못박힌 규칙

| 항목 | 내용 | 출처 |
|---|---|---|
| 손익비 | 기본 **1:3**. 변동성 낮고 거래량 큰 메이저는 **1:2**로 조정 가능 | 2-3, p27 |
| 진입 근거 | **2개 이상** 쌓을 것 | 3-10, p124 |
| 분할 | 몰빵 금지 — **분할 진입 + 분할 청산 필수** | 2-4 p30, 3-10 p124 |
| 손절·익절 | 진입 **전에** 확정. 손절은 시나리오 이탈 지점 | 2-4 p30, 3-10 p124 |
| 지표 파라미터 | 이동평균 **50**(단기 타점) / **200**(중장기 추세, 일봉·4h·1h) · 거래량가중(VWMA) **100** | 3-9, p102 |

## 층 2 — 재량 판단

- **어떤 근거 2개를 쌓을지는 자유.** 가이드의 예시: 주요 지지선 근처 · 이동평균
  400선 리테스트 · RSI 과매도 · 뉴스/거시경제 흐름 · 거래량가중 100 돌파 실패
  (3-10, p124)
- **지지·저항·매물대 위치를 사람이 작도.** "15분봉 200MA 지지, 전고점 저항,
  주요 매물대 등 객관적 기준" (2-4, p30)
- **보조지표 교차 확인.** "RSI 과매도/과매수, Total 2·3 지지선 등과의 교차 확인"
  (2-4, p30)
- **멘탈 점검이 체크리스트에 포함** — 감정 상태, 직전 손익의 영향, 집중 가능
  여부, 중독 여부 (2-4, p30). 자동화 불가능한 항목이다.
- **시나리오를 사람에게 검토받으라** — 커뮤니티/멘토 피드백 루프 (3-10, p124)

## 익절 설계 예시 (원문)

> "1차 저항선인 거래량 가중 100에서 50% 비중 익절, 2차 저항선인 200이동평균선에서
> 전부 익절" — 3-10, p124

익절선을 **비율이 아니라 구조(저항선)에 건다**는 점이 핵심이다.

## 이 프로젝트가 어떻게 옮겼나

| 가이드 | 구현 |
|---|---|
| 손익비 1:3 / 메이저 1:2 | `RiskEngine` — `rr_min_alt=3.0`, `rr_min_major=2.0` (BTC·ETH) |
| 근거 2개 이상 | `TradePlan.evidence` (len ≥ 2 검증) |
| 분할 진입·청산 | `entry_fractions=[0.5,0.25,0.25]`, 분할 TP 레그 |
| 손절 사전 확정 | 플랜 승인 시 손절가 확정, 4h 종가 판정 |
| MA 50/200 · VWMA 100 | `ma_confluence`, `vwma_support` 템플릿 |
| 매물대 | `vpvr_accum`, `box_range` |
| Total 2·3 / 도미넌스 | 레짐 프록시 (ALT_INDEX / DOM_PROXY) |
| 캔들 패턴 | `candle_breakout` |
| 톱다운 | `topdown_pullback` |
| 멘탈 체크 | **구현 불가** — 코드에는 감정이 없으므로 해당 없음 |
| 사람의 작도·재량 | **템플릿으로 대체** — 재량 대신 6개 템플릿이 근거를 자동 생성 |

핵심 차이: 가이드는 사람이 매번 판단하고, 이 시스템은 **판단을 템플릿으로 고정한
뒤 파라미터를 백테스트로 탐색**한다. 규율(층 1)은 그대로 강제하지만, 재량(층 2)은
기계화 가능한 형태로 좁혔다.
